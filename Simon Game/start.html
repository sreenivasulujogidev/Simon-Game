How to play Simon Game

1️⃣ To Start the game Press any key on the Keyboard (Say ENTER)
Then Simon flashes one color (e.g., Green)

2️⃣ Repeat the sequence i.e you have to press the same Color (Green)

3️⃣ Next round Simon adds one more color
Example: Red => You must press: Green → Red (in order)

4️⃣ Keep going Every round:
Simon repeats the old sequence Then adds one new color
Example later rounds: Green → Red → Blue → Yellow …

5️⃣ Game over If you press the wrong color or wrong order ❌
Game ends and restarts from level 1
